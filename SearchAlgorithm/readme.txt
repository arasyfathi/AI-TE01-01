# 🔍 Python Search Algorithms Collection

Repositori ini berisi kumpulan implementasi algoritma pencarian (Search Algorithms) menggunakan bahasa pemrograman Python. Terdiri dari *Uninformed Search* (Pencarian Buta) dan *Informed Search* (Pencarian Berheuristik).

## 📋 Daftar Algoritma yang Tersedia

1. **Linear Search** (`linear_search.py`)
2. **Binary Search** (`binary_search.py`)
3. **Breadth-First Search / BFS** (`bfs.py`)
4. **Depth-First Search / DFS** (`dfs.py`)
5. **Uniform Cost Search / UCS** (`ucs.py`)
6. **Iterative Deepening DFS / IDDFS** (`iddfs.py`)
7. **A* Search (A-Star)** (`a_star.py`)
8. **Dijkstra's Algorithm** (`dijkstra.py`)

## 🛠️ Persiapan Lingkungan (Environment Setup)

Kode ini ditulis menggunakan standar Python murni (*built-in libraries*) seperti `collections` dan `heapq`. Oleh karena itu, Anda **tidak perlu menginstal library eksternal** (seperti `pip install ...`). 

Namun, untuk menjalankan kode ini, pastikan komputer Anda telah memenuhi syarat berikut:

### 1. Instalasi Python
Pastikan Anda sudah menginstal Python (disarankan versi 3.6 ke atas).
- Download Python di situs resminya: [python.org/downloads](https://www.python.org/downloads/)
- Cek instalasi dengan membuka Terminal (Mac/Linux) atau Command Prompt (Windows) dan ketik:
  ```bash
  python --version
